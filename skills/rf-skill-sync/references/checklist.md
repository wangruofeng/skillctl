# 同步前检查清单

## 调用前确认

- [ ] 确认当前目录是项目根目录或在 git 仓库内
- [ ] 确认 `.claude/skills/` 目录存在且包含需要同步的 skills
- [ ] 首次运行时，先使用 `--dry-run` 预览变更

## 预期行为验证

- [ ] 输出包含"源 skills"列表，数量正确
- [ ] 输出包含明确的目标目录列表
- [ ] 变更摘要格式为 `+N / -N / =N`
- [ ] rf-skill-sync 不在同步列表中（自排除）
- [ ] 所有软链接都使用相对路径 `../../.claude/skills/xxx`

## 异常处理

如果遇到以下情况，请手动干预：

1. **"是真实目录，不是软连接"**
   - 确认该目录是否可以安全删除
   - 如果是旧的拷贝版本，手动删除后重新同步

2. **软链接指向错误路径**
   - 脚本会自动修复，无需手动干预

3. **目标目录下有非 skill 文件**
   - 脚本不会触碰，保持原样

## 验证同步结果

```bash
# 验证软链接是否都指向正确
find .codex/skills -type l -exec ls -la {} \;

# 检查是否有断链
find .codex/skills -type l ! -exec test -e {} \; -print
```
