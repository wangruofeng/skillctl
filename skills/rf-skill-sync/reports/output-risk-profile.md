# 输出风险评估

## 风险等级：低

## 已知风险场景

### 1. 误删风险
- **场景**：用户在目标目录下有真实目录，脚本可能误判为需要覆盖
- **防护**：检测到真实目录时直接跳过并输出警告，不执行删除或覆盖
- **验证点**：检查日志中是否有"是真实目录，不是软连接"提示

### 2. 路径错误风险
- **场景**：在非标准目录结构下，相对路径 `../../.claude/skills/xxx` 可能失效
- **防护**：脚本在项目根目录执行，路径结构固定
- **验证点**：运行 `find .codex/skills -type l ! -exec test -e {} \; -print` 检查断链

### 3. 空同步风险
- **场景**：`.claude/skills/` 为空或不存在，导致没有任何 skill 被同步
- **防护**：脚本依赖 shell 的 glob 行为，空目录时 `* /` 不会展开，`source_names` 为空
- **改进建议**：可以在脚本中增加源目录存在性检查

### 4. 隐蔽失败风险
- **场景**：`set -e` 可能导致脚本静默退出
- **防护**：每个操作都有显式日志，最终会打印"同步完成"
- **验证点**：确认输出包含"=== 同步完成 ==="

## 风险缓解建议

1. 首次运行必用 `--dry-run`
2. 同步后检查断链：`find .xxx/skills -type l ! -exec test -e {} \; -print`
3. 检查输出摘要数字是否符合预期
4. 对警告信息保持敏感
